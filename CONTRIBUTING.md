# Contributing

Thank you for helping maintain Awesome Super-Resolution in the Dark.

## Inclusion criteria

A paper should explicitly study spatial super-resolution under low-light, dark, nighttime, or underexposed conditions. Works that only perform low-light enhancement or standard super-resolution are outside the core scope, but may be proposed for the clearly labeled adjacent section when they materially influenced the field.

## Before submitting

1. Search the README for the title, DOI, and method name to avoid duplicates.
2. Prefer the publisher, conference, DOI, or arXiv page as the paper link.
3. Link only author-maintained code as **Code**. Label repositories without the promised implementation as **Announced**.
4. Verify the publication year and venue. Distinguish a preprint from a peer-reviewed publication.
5. Add the item to the most specific section and preserve reverse chronological order.

## Pull request format

Include:

- paper title and method name;
- authors;
- venue and year;
- stable paper/DOI URL;
- official code, project, and dataset URLs, if available;
- input type (single image, RAW/sRGB, burst, or video);
- one sentence explaining how the work addresses coupled low-light and low-resolution degradation.

Please keep each pull request focused. Do not add citation counts, unverified performance claims, copied abstracts, referral links, or unofficial code without clearly labeling it.

## Corrections

Metadata corrections are as valuable as new entries. When reporting a broken link or incorrect venue, include an authoritative replacement source.
